# TripDash · base OBDb convertida

Datos de diagnóstico por modelo derivados de [OBDb](https://github.com/OBDb), proyecto comunitario,
con licencia **Creative Commons Attribution-ShareAlike 4.0** (ver `LICENSE`). Esta versión se
distribuye con la misma licencia.

Cambios respecto del original: formato compacto, nombres traducidos al español, unidades
convertidas a métrico; se omiten comandos de línea K, los que requieren sesión de diagnóstico o
direccionamiento extendido, y datos de carrocería. `convert.py` es el script de conversión.

Usada por la app TripDash (iOS), que incluye estos archivos sin descargar nada.
